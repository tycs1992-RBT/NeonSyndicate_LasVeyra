All new art is original repository-native C# geometry or procedural animation. No downloaded model, paid asset, FBX, glTF, mocap, generated concept image or recorded VO is represented as imported production art. All predecessor binaries/GUIDs remain byte-preserved.

BodyBuilder records semantic eyelid, brow and lip vertex ranges as those features are emitted. It creates three sparse blendshape delta streams after the final topology is known. HumanoidRig uploads them to the existing mesh and caches their indices; HumanoidAnimator drives periodic blink and context expression weights. Other vertices—including eyeballs, skull, clothing and skeleton—receive zero delta. This preserves UV/detail/tangent/weight streams, original bones and draw material. The original hero budget remains 13,500; Malik is 12,988 vertices/18,092 triangles; Luma is 8,640/14,078. Blink max displacement is approximately 18.6 mm Malik / 13.0 mm Luma. Brow/warmth are much smaller. They require render review for seams/eye coverage; these are not a jaw/phoneme rig.

Crowd detail 0 and humanoid creature meshes do not gain facial channels. Three full-length CPU delta arrays cost 36 bytes per detailed vertex before Unity upload; native memory and GPU blendshape costs remain unprofiled. Existing pose visibility/LOD updates remain authoritative. Rebuilding clothing reconstructs and recaches the shapes with the new mesh. OwnedMeshes retains mesh disposal.

New arrival tracery is batched into existing stone/metal architecture batches, with lower detailed cost and all vertices above 6 m in its tested footprint. Seven mission-owned set types use two shared materials and no added collision/light components. Luma's lantern has geometry on her existing left-hand bone, with the original mission lamp owner. All sets live in MissionContext.Objects and are removed by normal mission cleanup.

Locomotion remains procedural. Added lateral-start/stop torso balance and pivot counterbalance run before the original action/IK pipeline and suppress combat/carry/travel/ride. Quadruped/grounded winged attention reuses existing neck/jaw/ear bones; attacks/hurt/movement suppress it. Existing 04K anatomy, skins and canonical drake evolution stages are retained.

`tools/export_cinematic04l_art.py` extends the existing compiled skin exporter with Luma and actual facial delta arrays. At the initial 6020332 source checkpoint it was executed against the exact managed-compiled game: eleven skins exported and validated for stream sizes, finite values, weights, joints, triangle indices and facial bounds. Evidence/art-export.json includes hashes. This is inspectable weighted data; no Unity screenshot or Blender import was run. The older 04K Blender bridge remains intact and does not itself establish facial import or a native playtest.

The continuation changes camera framing, pause and lifecycle logic; it adds no mesh or clip. Earlier geometry/skin export evidence remains historical and is not a new native render. Humanoid pose updates now explicitly stop during Pause.
