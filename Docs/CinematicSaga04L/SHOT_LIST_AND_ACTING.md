MissionContext is the sequence owner. `Talk` calls Begin/Line/Tick/EndPerformance04L; `Say` owns subtitle timing and existing confirm/skip. End is called from finally, mission cleanup before coroutine-stack removal and OnDisable. Timed actor leases also expire if their caller disappears. No extra update singleton, animation controller, authoritative root motion or cinematic save state was introduced.

`MissionContext.Cast04L` stages only nine whitelisted adult contacts near their original POI, in a clear same-floor capsule with head LOS. Existing mission bodies win. The existing CampaignDirector disables its story identity before the mission owner creates that same identity. Story cleanup destroys the staged body; Sable is explicitly released before the original hostile Sable. Luma, Warden, Third Eye and phone/radio speakers are never fabricated. If safe space/body is unavailable, dialogue retains the normal player camera.

The camera vocabulary is TwoShot, Shoulder, Close, Pullback, Reveal and Tracking. A stable player/actor axis keeps shots on one side. Chapter 0/11 begin with reveals; 4/5/8 favor shoulder/pullback; 9/10 favor shoulder/close. CameraShake off or reduced effects removes authored drift. PlayerCamera checks a sphere cast to the **interpolated** camera position, then restores the pre-sequence yaw/pitch on return. Actual collision quality still needs Unity.

Acting uses Resolve/Wonder/Concern/Warmth/Defiance/Grief, not phoneme lip sync. Head/chest/forearm and open-hand overlays are suppressed by movement, attacks, aiming, guard, cover, travel, riding, stagger, carry and other actions. Luma uses the smaller child profile. Named characters use existing roster costumes, with scene-safe facial channels. There is no recorded speech. Radio lines do not resolve into nearby bodies.

In a safe scene: Enter/A advances one line; Backspace/B skips the remainder. Held input on the first shown frame is ignored. Pause uses the existing time/input system; disconnect has no required input because lines expire. A threat, damage or displacement releases owned cinematic control and cancels remaining talk. Native interruption tests are still required. Giver greeting replay uses an existing quiet zero-reward MissionDef; it never changes story progress or pays a mission reward.
