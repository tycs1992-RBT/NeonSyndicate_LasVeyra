# Build 02G QA record

## Baseline

Reconstructed from the supplied 01C project, the committed 02D changed-files package and the supplied 02E/02F updates. GitHub's art branch still ends at 44a4ef4; later local updates were not assumed to be uploaded. Installer hashes validate the required files on the user's machine before writing.

## Executed checks

See BUILD_02G_SOURCE_ASSET_CHECKS.json, BUILD_02G_REFERENCE_MODEL_TESTS.json, BUILD_02G_PRESERVATION.json and BUILD_02G_INSTALLER_POLICY_TESTS.json for results generated by the actual check runs.

Source checks validate lexical delimiters, integration entry points, new metadata, known material IDs, node/asset references and forbidden new gameplay mutations. WAV payload checks validate format, duration, peaks and endpoints. Pedestal bounds are measured from the actual reused OBJ vertices. None of those checks is a C# grammar parser, compiler, Unity renderer or runtime simulation.

Python reference-model tests explore puzzle orders, wrong inputs, partial reward credit, callback failure/re-entrancy, old saves, snapshot copying and randomized action sequences. They validate a separately implemented specification, not execution of the shipped C# code.

Installer-policy tests exercise package hashes and a Python simulation of validation, copying, rollback, path rejection and refusal to overwrite user changes. They do NOT run PowerShell or Windows.

## Native tests supplied, NOT executed

Discovery02GTests covers catalog validation, state progression, independent shrine resets, repeat claims, partly pending credits, reward reservations, callback failures, re-entrant use, circuit completion, save sanitization, old saves, round-trip JSON and shipped material references. Native JSON and Resources tests are marked with the existing NeedsEngine category. The previous unsupported NonParallelizable attribute is not used.

No Unity Editor, .NET SDK, Mono C# compiler or PowerShell runtime is available in this build environment. Attempts to obtain a compiler were unsuccessful; no native test pass is claimed.

## Known risks requiring Unity

Ground placement may fail for a particular city seed or settle among collision-free decorations. The system reports skipped locations instead of destroying obstacles. The last unresolved site blocks the circuit reward rather than lowering the goal secretly. Relative label orientation, scene lighting and new shader reuse still need visual review. Text may need layout tuning for uncommon aspect ratios. The package does not claim 60 FPS.

## Saving and rollback

There is no forced autosave. Use the existing save menu. The installer creates a dated external backup and guarded restore script. Restore refuses post-install edits. An older game can ignore the appended Discovery JSON block; saving from the older game can omit that activity data. Preserve your game saves before testing rollback. Do not delete the test suite or change Unity versions to work around an error.

## Checker location

Run the Python checkers from the installed full project after applying the update. The update Payload intentionally contains only changed files and is not a stand-alone Unity project. The source checker rejects that incomplete context instead of treating it as a failing game build.
