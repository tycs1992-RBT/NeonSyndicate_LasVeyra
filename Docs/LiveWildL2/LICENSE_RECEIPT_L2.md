# Original Redspire rights receipt

All L2 geometry, UVs and maps are original project work generated and refined for this delivery. No third-party mesh, scan, texture, archive, plugin or executable is an art input. No purchase occurred. The project dedicates these original asset files to the public domain under CC0-1.0, as recorded in each family's CREDITS.txt and ASSET_MANIFEST_L2.json. Public raw-source publication is allowed under that dedication.

Admitted paths: ArtSource/RedspireL2/RedspireWildernessL2.blend; eighteen named A/B LOD0/1/2 FBXs in Assets/NeonSyndicate/Art/LiveWilds/Boulder, RockSpire and DeadTree; six PNG maps in LiveWilds/Shared. There are no rejected extracted archive paths in this sprint because no archive extraction is used. Earlier asset rights remain under their existing receipts and are not reinterpreted here.

Tools are not incorporated as art. Blender authored/exported/reimported the models. The independent parser is fetched at its pinned public source revision by CI; its source is not vendored into the game. Distribution of the parser itself is not claimed by the asset dedication.

Source generator: tools/author_redspire_l2.py. Receipt records exact byte lengths, SHA256 hashes, source bounds and measured LOD triangle counts. Do not reseal a receipt merely to bypass a failed import or license check. Review any changed input before replacing it.
