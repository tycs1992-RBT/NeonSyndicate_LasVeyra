# Optional imported character foundation

ASSET REQUIRED. No professional FBX, rigged creature, authored animation clip or texture was supplied. The game continues using the procedural bodies by default. Nothing in this delivery proves an imported character's native appearance.

Place lawful supplied art under Assets/NeonSyndicate/Art/Imported/<identity>/Models, Textures, Materials, Animations and Prefabs. Existing FBX/texture Git LFS rules apply; preserve Unity-generated sidecars and reference GUIDs. Do not replace canonical scripts or install another movement, inventory, damage, spawn or save package.

Create a registry with Create > Neon Syndicate > Imported model registry 04OD, save it as Assets/NeonSyndicate/Resources/ImportedModels04OD.asset, and initially leave Enabled false. Add explicit identities: malik, npc:Dante Rook, creature:veilglass_castellan, creature:stormroot_sovereign. The registry and each row must both be enabled after native validation. No registry is shipped with invented asset references.

For a humanoid, author one distinct TargetPath for every original HumanoidRig.Bones index. RigLayout.Names and indices are the authoritative source. The original detailed human rig includes fingers; all original pose bones must map exactly once. A nonhumanoid uses its existing CreatureRig.Bones indices. Every weighted target skin bone must be mapped. The initial adapter deliberately rejects arbitrary extra weighted bones; it does not automatically retarget arbitrary humanoid avatars or authored animation clips.

Required humanoid visual sockets: hand_r, hand_l, foregrip, muzzle, blade_hilt, blade_tip, head, chest, fx, synergy. Creature adapters require head/chest/fx/synergy. These are visual validation locators, not a replacement for the original weapon muzzle, swept blade, collider, aim or hitbox owners. The imported hand placements must match the original authoritative grip positions during the native smoke test. Use actual mesh bounds and inspect all weapons. The adapter follows original bone positions and bind-relative rotations after the procedural pose; original health, colliders, root motor, weapon attachments, camera and controls stay authoritative.

The prefab must contain skinned meshes, valid supported materials and no physics or gameplay MonoBehaviours. Its Animator is disabled because the original pose drives it. Missing prefab, unsafe scale, incomplete/duplicate mapping, missing sockets, unmapped weighted bones or unsupported materials retain the original renderer. Runtime death/ragdoll or adapter disable restores the procedural renderer. Registry cache joins Game.ResetStatics. Current fallback on ragdoll stays procedural for that actor afterwards; automatic imported recovery is not production-complete.

Run Neon Syndicate > 04OD > Audit imported models in the actual licensed Editor. It reports rigged meshes, humanoid avatar validity, basic scale and materials without rewriting import settings. Zero imported models reports ASSET REQUIRED. In Play Mode select the actual Malik/creature and use Smoke test selected visual fallback; it only requests the adapter and is not an automated pass.

Native acceptance: T-pose/scale/bones, original skin fallback, all gait/attack/dodge poses, hand and gun alignment, exact blade contact, muzzle/FX positions, subtitle/cinematic Pause, creature tells and parts, death/ragdoll, vehicles/flight, saved ownership, all graphics presets and Built-in/optional URP. Author LOD/material conversion and expressions against real supplied assets. No FBX import, animation quality, LOD or performance has been verified here. Bonded-drake art mapping remains an additional adapter task because its dedicated companion rig is not the CreatureDirector body path.
