# 04OG import and art status

No professional rigged model, FBX, texture set, motion-capture or authored animation clip was supplied or imported in this sprint. Those content requirements are **ASSET REQUIRED**. Existing procedural Malik, canonical NPCs, creatures and fallback visuals remain.

The original visual-only FBX adapter/wizard remains the import path. Both editor audit and runtime validation now reject mirrored, collapsed or nonuniform local transforms that rotation-only retargeting cannot safely repair. The report identifies the offending node and asks the artist to apply transforms and re-export. Unsupported art leaves the original visual enabled. Positive uniform local scales, complete unique bone paths, matching bind poses, visual sockets and current-renderer materials are still required. Built-in and optional URP compile configurations pass; actual shader rendering and supplied-avatar deformation remain NOT RUN.

Use `Neon Syndicate > 04OF > Imported visual wizard` (or the acceptance panel's wizard button). Select a licensed skinned Project model, choose the canonical identity and source rig, map every source bone, inspect passive descendants, set locators, audit and create a disabled registry row. Inspect scale, pivot, handedness, skin deformation, weapon grip, materials, LOD and fallbacks natively before enabling it. Original controllers, colliders, damage, inventory and animation ownership must not be placed on the imported visual prefab. The adapter currently uses original procedural poses; finding clips does not activate or retarget them.

Runtime references are in original CreatureAbilityKit, RegionalBossPresentation, CityBuilder and profile dispatch. Source OBJ exports in Evidence04OG are the emitted meshes, **not screenshots, professional assets or visual acceptance**.
