# Owner walkthrough

1. In GitHub Desktop select `feature/04oh-ascension-art-foundation`, then Fetch and Pull. Keep your own unrelated changes.
2. Open the existing project in Unity 6000.3.16f1 and wait for import. Open **Neon Syndicate > Acceptance > Verify Fantasy World** and check preparation.
3. Start the existing **PLAY FANTASY WORLD** session. In Pause > EXPLORE, select **Route: Stone threshold**, then **Route: Mineral grotto**, then **Route: Woodland causeway**. After each choice, close Pause and follow the existing GPS.
4. An active mission can take priority over your waypoint. If you want your tracked campaign lead back, clear the waypoint on the map. Quest availability and rewards follow the original JOURNAL and Dante interaction.
5. Return to the Forge and check doors, walkable routes, camera and the companion. Test a save/reload and controller separately. If a route or import fails, keep the first Console error and stop the review.

These are review instructions, not a claim that any step passed. The checkpoint does not create new art. The wider fantasy environment and native acceptance remain unfinished.
