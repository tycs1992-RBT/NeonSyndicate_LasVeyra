## Production handoff requirements

Every commissioned or licensed package should arrive with source files, unit/orientation notes, naming and material slots, pivots, texture channel/color-space definitions, rig/animation notes where relevant, deliberate LODs and simple collision proxies. Record provenance and redistribution rights for each imported package. Keep reference images as direction only, not reusable commercial game assets.

Texture resolution and triangle count should follow actual camera exposure, UV coverage and measured target hardware. A nominal high polygon count or large texture dimension is not an acceptance test. Approve one representative object in the running district before producing its whole family.

## Work that is primarily implementation or look development, not a missing model

The district still needs a real Unity lighting/material review, carefully budgeted reflection support where appropriate, assessment of shadow/AO quality, matched screenshots, camera/HUD obstruction checks and target-desktop profiling. Volumetric shafts, true crystal transmission, wet-surface reflection accuracy and global illumination are rendering decisions with integration and cost implications. They are not automatically provided by adding art meshes.

## Suggested next production gate

Approve one street frontage, one grove corner, one drake close-up and one short spell sequence in the actual game before scaling any package to the whole world. Record exactly which presentation targets passed and which remain provisional. Keep the existing gameplay and story build as the comparison baseline.
