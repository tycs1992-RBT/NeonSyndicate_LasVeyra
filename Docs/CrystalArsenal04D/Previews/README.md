
## Image files

The offline preview renders (foci line-up, silhouettes, each focus, shots, case and target, focus marker) were made
by the art harness but are not committed: the cloud session that produced them cannot upload Git LFS objects (the
repository routes PNG files through LFS). They were delivered to the owner directly in the session. They are flat
offline renders, not in-game captures, and no game asset depends on them; every focus, shot and prop is generated by
C# at runtime.
