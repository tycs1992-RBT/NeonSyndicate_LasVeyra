# Actual authored motion and ownership contract

Five actual editable Blender actions, not procedural source poses: `H7_IdleBreath` (3 s), `H7_Walk` (1.6 s), `H7_Run` (0.8 s), `H7_SwordReady` (2 s), `H7_OathCut` (1.2 s), 30 fps. Rig-only FBX names include the `MalikRig|` prefix. Original H6 53-bone hierarchy and ten visual locators are retained; 47 original semantics still map through ImportedBindH3. Source actions use no animation events and no displaced root. Their genuine curve/key counts, sampled frames and hashes are in the manifest and evidence.

The loop inspection caught a real end-key mismatch in walk/run. The closing keys were corrected to the authored first pose and quaternion signs made continuous. The failed first inspection is retained under EvidenceH7/Development. The unchanged closure test must pass before final motion delivery. This is an asset fix, not a changed test threshold.

Only optional Editor-review torso accents are connected. `MalikMotionH7.json` samples real authored chest/neck/head world-rotation deltas, converted to canonical actor-local axial `(x,-z,y,w)` from Blender. Native axis/appearance acceptance remains NOT RUN. No additional Animator or motor runs. ImportedVisual04OD composes an accent before its one existing final world-rotation assignment per bone. It continues assigning original bone positions and later original child world rotations, so hands, feet, fingers and gameplay weapon sweeps retain original authority.

Idle accents are allowed only in quiet grounded idle, capped at 25 percent, fading in over 0.3 s. The right-cut accent requires original HoldBlade, unmirrored SlashRight and original AttackT. AttackT, AttackWindup and AttackActive are **normalized by the original move total**. The original windup maps to authored phase 0-0.36; original active maps to 0.36-0.55; original recovery maps to 0.55-1. No independent action timer, hit event, damage, resource spending, unlock or root motion is added. Original cancellation immediately removes the selected action. The original pose still determines every actual weapon contact.

Aim, guard, dialogue/look/inspection gestures, Dodge, stagger, drink, parry, throw, older melee swing, crystal cast, Resonance, cover, crouch, vehicles and travel exclude the accents. Pause returns through the existing paused owner; it cannot consume actions or advance damage. Existing Restore clears the data/clock, restores fallback and scoped skin quality; import changes and window close/reload stop the review. These cleanup paths are source-integrated, **not native tested**.

The full-body walk/run/ready/cut FBX is available for native Animation-tab review but remains SOURCE INCOMPLETE for gameplay playback. Foot sliding, root/hip alignment, finger closure, deep coat collision, weapon grip and recovery blending need actual Windows Editor acceptance and additional art work. The source Oathblade study uses the unchanged canonical weapon builder; it is never embedded in the actor FBX or granted to inventory. Dodge/jump/land/gun/cast/flight and facial clips remain ASSET REQUIRED.
