# One native fantasy-world check

Fetch and Pull the existing feature/04oh-ascension-art-foundation branch in GitHub Desktop. Do not create a local commit simply to download this work. Open that repository project in Unity6000.3.16f1 and wait for imports.

1. Choose **Neon Syndicate > Acceptance > Verify Fantasy World**. Click **1. Verify preparation** outside Play. The tool reads the real local Git checkout, checks art bytes and Unity imports, rebuilds characters and both district catalogs, and writes the version stamp locally. A blocker stays visible; it does not become success because preparation was requested.
2. Click **2. Begin native review: PLAY FANTASY WORLD**. The optional private save backup is enabled by default. The existing game scene and revision-10 Free Roam are used. Ordinary gameplay save behavior remains; backups are copy-only and never automatically restored or uploaded. The central title button offers the same temporary session preview. Existing appearance defaults stay unchanged.
3. In ordinary play inspect the first home view, walk west through Living Streets, face north toward the gate/Archive, and reach an existing safe elevated overlook. At each view, choose HOME, STREET, SANCTUARY or ELEVATED in the acceptance window and click **Capture matched OFF / ON pair at this view**. Keep the Game view visible. The tool freezes and restores the existing camera, clock, HUD and input for the pair; it does not teleport the player or run the ordinary QA tour.
4. Return through the existing court to Forge/Dante and use the original interaction. Capture GAMEPLAY as a current frame. Complete only the checkboxes actually tested: materials, route and collision, controller/quality, saves/vehicle and interaction. Pixel change alone cannot approve the architecture or gameplay.
5. Click **3. Export JSON, screenshot comparison and readable results**. The local folder is **UserCaptures/FantasyWorldProof/<session>/**. Open FANTASY_PROOF_README.txt, FANTASY_COMPARISON.html and FANTASY_PROOF.json. Actual PNG files exist only after real rendered frames were saved. Review logs/images before sharing; nothing is automatically uploaded or committed. Private save copies are separate in UserBackups/FantasyWorldProof/<session>/.

F2 > Fantasy proof shows the actual Git commit, source fingerprint, Unity/world/renderer/quality, player position, valid imported models, instantiated objects, selected flags, policy activation, observed active objects/renderers, nearby and camera-frustum candidates, and first source/native/activation refusals. Frustum candidates do not prove occlusion, actual LOD draw selection or artistic quality.

If the title action reports a missing stamp, stop Play and run the acceptance menu in this project. If the SHA is old, use Fetch/Pull on this repository and reopen that project, preserving unrelated local edits. A ZIP outside Git cannot identify a genuine checkout and remains BLOCKED. GitHub Desktop's bundled Git is supported; a separate command-line Git installation is not required for the real SHA. Dirty status is explicit when it cannot be measured.

If the editor is closed on Windows, double-click **VerifyFantasyWorld.cmd** in the repository. It looks for the exact required installed Editor, or asks you to select Unity.exe. It opens the same acceptance window. If this project is already open, it tells you to use the existing Editor menu. This launcher has not been executed on Windows here. No Editor is downloaded or license activated by it.

No native screenshots, visual score or gameplay completion are asserted by this document. The remote worker did not run your Windows Editor.
