# Source rights and production provenance

The two newly authored Blender models and two new texture families are original project-authored content released under CC0-1.0. Existing project textures, skeleton data and pose authority are reused under their existing ownership and licensing; their original files are preserved. No external commercial model or animation was imported.

These assets were authored locally through Blender Python with AI assistance. They were not generated by Tripo. There was no configured API key, connected provider, paid task or credit spend. The optional external adapter supports reviewed text/image generation requests but defaults to no spending. Future provider outputs must retain their actual provider terms, source rights and approval receipts. They must never be relabelled CC0 merely because this demonstration uses original content.

The existing game's native import, visual quality, motion, collision and artistic acceptance gates remain independent of source rights and source-level mesh validation.
