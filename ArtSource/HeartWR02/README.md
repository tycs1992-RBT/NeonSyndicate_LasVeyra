# Editable WR02 natural crowns

Three original normalized foliage families, with three silhouette levels each. The game fits only noncolliding leaf crowns to actual source envelopes. Original trunks, roots, cliff geometry, physical terrain and world placement owners remain. These are not whole-tree or new traversable-terrain replacements.

Run tools/texture_surface_wr02.py, then run Blender in background with tools/build_canopies_wr02.py. Source images are packed. Source generation never modifies old assets. The five shared surface families each have albedo, tangent normal and metallic/smoothness maps. CC0-1.0, original project-authored source. Native acceptance NOT RUN.
